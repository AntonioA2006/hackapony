# Sistema de diseño (propuesta)

## Paleta

| Token | Hex | Uso |
|-------|-----|-----|
| `primary-600` | #0369A1 | Acciones principales (agua) |
| `primary-700` | #075985 | Hover |
| `accent-500` | #06B6D4 | Mapas, links |
| `success-600` | #059669 | Resuelto |
| `warning-500` | #F59E0B | En revisión |
| `danger-600` | #DC2626 | Crítico / error |
| `neutral-900` | #0F172A | Texto |
| `neutral-100` | #F1F5F9 | Fondos |

## Tipografía

- Sans: **Inter** o **Source Sans 3** (webfont).
- Escala: text-sm base text-lg títulos.

## Componentes reutilizables

| Componente | Uso |
|------------|-----|
| `Button` | primary, secondary, danger |
| `StatusChip` | estados reporte |
| `PriorityBadge` | bandas urgencia |
| `Card` | dashboard |
| `DataTable` | admin con paginación |
| `MapContainer` | wrapper Leaflet |
| `EmptyState` | listas vacías |
| `Toast` | confirmaciones |
| `Modal` | duplicados sugeridos |

## Espaciado

- Grid 4px; contenedor max-w-7xl admin, max-w-lg formulario móvil centrado.
